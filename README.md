# scrapy_quotes

A [Scrapy](https://scrapy.org/) spider that scrapes every quote from
[quotes.toscrape.com](http://quotes.toscrape.com/), a sandbox site built for
practicing web scraping.

## Requirements

- Python 3.9
- [pipenv](https://pipenv.pypa.io/)

## Setup

```bash
pipenv install
```

## Usage

Run the `quotes` spider and write the results to a file. The format is picked
from the extension (`.json`, `.jsonl`, `.csv`, `.xml`):

```bash
pipenv run scrapy crawl quotes -O quotes.json
```

`-O` overwrites the output file; use `-o` to append instead.

## Output

Each item has two fields:

| Field    | Description                                   |
|----------|-----------------------------------------------|
| `author` | The quote's author                            |
| `text`   | The quote, with the surrounding curly quotes removed |

```json
{"author": "Albert Einstein", "text": "Try not to become a man of success. Rather become a man of value."}
```

A full crawl visits all 10 pages and yields 100 quotes.

## How it works

The spider (`quotes/spiders/quotes_spider.py`) starts at the home page, yields
the author and text of each `div.quote`, then follows the `li.next` link until
it reaches a page without one.

## Project layout

```
quotes/
  spiders/quotes_spider.py   # the QuoteSpider
  settings.py                # Scrapy settings (obeys robots.txt, UTF-8 feed export)
  items.py, pipelines.py,    # generated by `scrapy startproject`; not used yet
  middlewares.py
quotes.json, quotes.csv      # sample output from earlier runs
scrapy.cfg                   # Scrapy project config
```
